# belle vision — Website

A multi-page portfolio/marketing website for **belle vision**, the AI-powered beauty matching platform.

> *Scan it. Match it. Wear it.*

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage — hero, stats, intro, how it works teaser |
| `pages/about.html` | About — mission, values, founding team |
| `pages/problem.html` | The Problem — why beauty shopping is broken |
| `pages/solution.html` | Our Solution — how BELLE works, competitive advantage |
| `pages/contact.html` | Contact — form + direct email |

## Tech Stack

- Pure HTML, CSS, JavaScript — no frameworks, no build step
- Google Fonts: Comfortaa (headings) + Hind (body)
- Fully responsive (mobile, tablet, desktop)
- Scroll-triggered fade-in animations
- CSS gradient blobs matching the brand identity

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://yourusername.github.io/repo-name`
